# 分析规则规范（Analysis Rules）

本规范定义分析系统的通用规则与科目级别解释结构。所有分析输出必须由规则表驱动，禁止在业务逻辑中硬编码科目分支。

## 分析系统通用规则
- 分析逻辑以 `shared/domain` 为唯一真源。
- 科目分析必须由规则表提供输出，不允许在 controller 内写 if/else 科目判断。
- 规则表缺失时，必须返回“unknown”风险等级与通用提示，避免伪造结论。

## 科目级别解释逻辑
每个科目的解释逻辑由规则表定义，输入为该科目成绩值，输出为统一结构：

```
riskLevel / summary / advice
```

### 规则说明
- `riskLevel`：风险等级（如 low / medium / high / unknown）。
- `summary`：对该科目成绩含义的简明解释。
- `advice`：针对性建议，必须可执行或可理解。

## 分析输出最小结构
任何分析结果中，科目级别解释至少包含以下字段：
- `riskLevel`
- `summary`
- `advice`

**禁止事项**
- ❌ 在分析流程中使用 subject === "公民与社会发展" 进行判断
- ❌ 在 controller 内写分析业务逻辑
- ❌ 绕过规则表直接拼接分析结论
